# 이론 ↔ 코드 위치 (찾기 쉽게)

메일 이론 정리의 각 개념이 **어느 파일 어디에** 있는지 정리. VS Code에서 바로 열어 확인.

---

## 주제 1 · REST API / FastAPI  → `01-fastapi/`

| 이론 개념 | 코드 위치 | 확인 포인트 |
|---|---|---|
| REST 메서드 (CRUD) · 상태코드 | `01-fastapi/todo_api.py` | `@app.post`(201) / `@app.get` / `@app.put` / `@app.delete`(204) |
| 검증 실패 → 422 | `01-fastapi/main.py` | `item_id: int` 타입힌트 → `/items/abc` 호출 시 422 |
| 없는 리소스 → 404 | `01-fastapi/todo_api.py` | `raise HTTPException(status_code=404)` |
| HTTP 헤더 (Content-Type 등) | `01-fastapi/client.py` (5번) | `headers = {...}` + `dict(r.request.headers)` 출력 |
| 인증 (Authorization·Bearer) | `01-fastapi/client.py` (5번) | `"Authorization": "Bearer my-test-token"` |
| FastAPI 기본 (Pydantic·엔드포인트) | `01-fastapi/main.py`, `todo_api.py` | `class Todo(BaseModel)`, `@app.post(...)` |
| 클라이언트가 API 호출 | `01-fastapi/client.py` | httpx로 POST/GET 호출 |

실행:
```
fastapi dev todo_api.py      # 서버 (다른 터미널)
python client.py             # 헤더·인증 포함 호출 (5번)
```

## 주제 2 · LLM Tool Calling  → `02-tool-calling/`

| 이론 개념 | 코드 위치 | 확인 포인트 |
|---|---|---|
| 도구 스키마 정의 | `02-tool-calling/manual_loop.py` | `TOOLS = [...]` (name·description·parameters) |
| agentic loop (수동) | `02-tool-calling/manual_loop.py` | `while True:` → 모델호출 → 도구실행 → 결과반환 |
| description 중요성 | `manual_loop.py` | 각 도구의 `"description"` 필드 |
| 프레임워크가 루프 대신 처리 | `02-tool-calling/langchain_agent.py` | `create_react_agent(...)` 한 줄 |

실행 (Ollama, 키 없음):
```
uv run --with ollama python manual_loop.py
uv run --with "langchain,langgraph,langchain-ollama" python langchain_agent.py
```

## 주제 3 · MCP  → `../mcp_example/`

| 이론 개념 | 코드 위치 | 확인 포인트 |
|---|---|---|
| MCP Server (Tools·Resources·Prompts) | `mcp_example/mcp_server.py` | `@mcp.tool` / `@mcp.resource` / `@mcp.prompt` |
| MCP Host + Client | `mcp_example/mcp_host.py` | `MultiServerMCPClient`(=Client), 전체 앱(=Host) |
| stdio 통신 | `mcp_example/mcp_server.py` | `mcp.run(transport="stdio")` |
| 등록 목록 확인 | `mcp_example/inspect_registry.py` | `mcp.list_tools()` 등 |
| 구조 그림 | `mcp_example/architecture.svg` | Host/Client/Server 다이어그램 |

실행 (Ollama, 키 없음):
```
python mcp_host.py                          # 대화형
uv run --with "mcp[cli]" mcp dev mcp_server.py   # Inspector
```
사내 재현: `mcp_example/SETUP-사내재현.md`

## 참고: 파일이 아니라 "개념 설명"인 것
- 메일의 `GET /todos/5 → 200 OK ...` 같은 **HTTP 요청/응답 예시**는 통신 형식을 글로 보여준 것 (코드 파일 아님).
  → 실제 동작은 `01-fastapi/client.py` 실행 결과로 확인.
