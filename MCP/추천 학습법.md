# MCP 추천 학습법 (여기부터 시작)

> 자료가 여러 개라 헷갈릴 수 있어, **무엇을 어떤 순서로 볼지** 정리한 문서다.
> 결론: **공식 정석 강의(영어) 1번 + 우리 워크북 직접 실습 + 한국어 자료 보충.**

## 추천 순서 (이대로만 하면 됨)

| 순서 | 무엇 | 형식 | 시간 |
|---|---|---|---|
| 1 | **DeepLearning.AI MCP 강의** 를 영어 자막으로 한 번 | 영상 (정석) | 약 1.5시간 |
| 2 | **우리 워크북 examples** 를 한국어로 보며 직접 손으로 | 실습 | 본인 페이스 |
| 3 | 막히는 개념만 **테디노트 한국어 자료**로 보충 | 텍스트/영상 | 필요할 때만 |

→ "공식 정석 + 직접 실습 + 한국어 보완"이 한 번에 채워진다.

---

## 1단계 — 정석 강의 (영어, 무료)

MCP를 **만든 회사(Anthropic)가 직접** 참여한 자료라 가장 정확하고 최신이다. 군더더기 없이 MCP만 정면으로 다룬다.

| 강의 | 분량 | 만든 곳 | 특징 |
|---|---|---|---|
| **[MCP: Build Rich-Context AI Apps](https://learn.deeplearning.ai/courses/mcp-build-rich-context-ai-apps-with-anthropic/)** (DeepLearning.AI) | 약 1시간 38분 | DeepLearning.AI × Anthropic (강사: Anthropic 기술교육 총괄 Elie Schoppik) | **사실상 정식 MCP 강의.** 서버 제작·테스트 → 챗봇 연결 → tools/prompts/resources → 서드파티 서버 연결 → Claude Desktop 재사용 → 원격 배포까지. 우리 워크북 실습 3과 범위가 거의 같다 |
| [Anthropic Academy: MCP 입문](https://anthropic.skilljar.com/introduction-to-model-context-protocol) | 짧음 | Anthropic 직접 | MCP 만든 회사의 공식 입문 |
| [Hugging Face MCP Course](https://huggingface.co/learn/mcp-course/en/unit0/introduction) | 유닛제 (수료증) | Hugging Face | 이론 + Gradio end-to-end |

> **"정석"의 의미 구분:** DeepLearning.AI는 *내용의 정확성·권위* 기준 정석이다. 다만 **전부 영어**다. 영어 자막으로 따라갈 수 있으면 1순위가 맞고, 영어가 부담되면 한국어로는 아래 3단계(테디노트) + 2단계(워크북)가 현실적인 정석이다.

## 2단계 — 직접 실습 (한국어, 이 저장소)

영상으로 그림을 잡았으면, 직접 손으로 만들어봐야 진짜 내 것이 된다.

- [MCP 실습.md](MCP%20실습.md) — 단계별 실습 워크북 (체크포인트·도전 과제)
- [examples/](examples/) — 바로 실행 가능한 코드 (FastAPI → Tool Calling → MCP 서버)
- [MCP 이론.md](MCP%20이론.md) — 개념 정리 + 추천 자료 (예습·복습용)

## 3단계 — 한국어 보충 (필요할 때만)

개념이 막히거나 한국어로 다시 정리하고 싶을 때만 본다.

- [테디노트 MCP 가이드: LangChain 기반 구축과 Cursor AI 연동 (WikiDocs)](https://wikidocs.net/book/17801) — MCP 전용 한국어 교재. LangGraph도 같이 하니 강사 연속성이 좋다
- [조코딩 유튜브](https://www.youtube.com/@jocoding) — 입문·쉬움, 빠르게 감 잡기
- [모델 컨텍스트 프로토콜 통합 가이드 (WikiDocs, FastMCP)](https://wikidocs.net/289908) — 서버 개발 한국어 문서

> **나중에(기초 익힌 뒤) 볼 것:** [전현준 × 테디노트 MCP/A2A 엔터프라이즈 집중탐구 (유튜브)](https://www.youtube.com/watch?v=z2rnK9COhuQ) — 강의가 아니라 3시간짜리 **대담**이다. 기초가 있는 상태에서 실무·업계 관점을 듣는 용도. 첫 자료로는 비효율적이니 순서상 마지막에.
